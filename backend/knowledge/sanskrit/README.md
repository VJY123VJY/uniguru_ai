# Sanskrit Knowledge Domain

## Overview

This directory contains the canonical Sanskrit knowledge used by the UniGuru Sanskrit Knowledge Decoder.

The knowledge is organized as immutable canonical concepts.

Each concept is represented as a standalone document that preserves:

- Śabda
- Dhātu
- Vyākaraṇa
- Nirukta
- Bīja
- Tattva
- Śakti
- Functional Meaning
- Cross References
- Canonical Sources

## Canonical Principles

- Every concept is immutable.
- Every concept has a unique ontology identifier.
- Every concept is replay-safe.
- Every concept must preserve provenance.
- Every concept participates in the Sanskrit Knowledge Graph.
